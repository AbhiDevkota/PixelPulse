# Contributing to PixelPulse

Thank you for your interest in contributing to PixelPulse! We welcome contributions of all kinds.

## Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/PixelPulse.git
   ```
3. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Building

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

## How to Contribute

- **New Games**: Add classic mini games to the console
- **Bug Fixes**: Fix issues in existing code
- **Features**: Implement new features or improvements
- **Documentation**: Improve guides and code comments
- **Performance**: Optimize existing code

## Code Standards

- Use C++11 or later
- Follow these naming conventions:
  - Classes: `PascalCase`
  - Functions: `camelCase`
  - Constants: `UPPER_SNAKE_CASE`
- Use 4 spaces for indentation
- Keep lines under 100 characters
- Write clear commit messages

## Submitting a Pull Request

1. Ensure your code compiles without warnings
2. Test your changes thoroughly
3. Commit with a descriptive message: `Add feature X` or `Fix bug Y`
4. Push to your fork and create a pull request
5. Fill out the PR description with what changed and why

## Reporting Issues

Please include:
- What you were trying to do
- What happened (unexpected behavior)
- Your environment (OS, compiler, CMake version)
- Steps to reproduce the issue

## Questions?

- Check existing [issues](https://github.com/AbhiDevkota/PixelPulse/issues)
- Look for `good first issue` labels to get started

Happy coding/Gaming!

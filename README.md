## How to Run

1. Clone the repo
```bash
git clone https://github.com/AbhiDevkota/PixelPulse.git
```

```bash
cd PixelPulse
```
2. Open `CMakeLists.txt` in Visual Studio and let CMake configure it 
3. Select **CoreZone.exe** as startup item
4. Hit the green play button

# <img src="assets\rocket\rocket_icon.png" width="30"/> ROCKET SHOOTER

 
This is a preview of the Rocket Shooter game inside the Pixel Pulse Arcade Zone.
## Description
Welcome to Rocket Shooter! This is an action-packed 2D-style pixelated game where you control your very own rocket ship with the main purpose of defeating your enemies and doging the incoming obstacles. It is designed with smooth controls and classical retro mechanics, it focuses on high-performance rendering and clean object-oriented design.

## Requirements
- Visual Studio 2022
- CMake 3.28+
- Git

  ## How to Run

1. Clone the repo
```bash
git clone https://github.com/AbhiDevkota/PixelPulse.git
```

```bash
cd PixelPulse
```
2. Open `CMakeLists.txt` in Visual Studio and let CMake configure it 
3. Select **CoreZone.exe** as startup item
4. Hit the green play button
5. Click Play and choose the Rocket Chooter Option
